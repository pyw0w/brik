# Modules live in the bot repo, contract kept package-ready

Сторонние модули принимаются в репозиторий бота через PR (поток вклада через ревью владельца), а не публикуются как npm-пакеты. Выбрано для старта: максимум контроля качества, единая документация, простое ревью. Но контракт модуля проектируется как изолированный пакет (зависит только от публичного API ядра), чтобы при необходимости добавить загрузку внешних пакетов без изменения ядра.
