# Documentation is a first-class deliverable

Документация — обязательная часть проекта, а не опция: README, CONTRIBUTING, гайды (getting started, первый модуль, dev-режим), справочник модульного API (ручной + TypeDoc из кода), глоссарий CONTEXT.md. Исходник — Markdown в репозитории (версионируется с кодом), собирается в сайт Vitepress с поиском. Язык — русский сейчас, структура заложена под перевод на английский (термины не зашиты в код, глоссарий двуязычен). Обязательное поле `description` в схеме каждого Handler-а питает `/help` и автоподстановку.
