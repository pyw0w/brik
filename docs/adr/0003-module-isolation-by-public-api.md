# Module isolation by public API only

Handler-ы не вызывают Handler-ы напрямую и не знают о существовании друг друга. Межмодульная связь — только через публичные функции модуля (обычные экспорты TS-модуля, например `economy.give(user, 10)`), которые объявляет `defineModule`. Это делает контракт модуля изолированным пакетом, зависящим только от публичного API ядра, и оставляет открытой дорогу к внешним npm-пакетам без переделки ядра.
