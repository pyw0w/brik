# Slash-commands as first-class surface, guild/global sync split

Команды бота — нативные Discord slash-команды, объявляемые один раз в схеме Handler-а (имя, аргументы, описание). Регистрация в Discord двухрежимная: в dev — на тестовую гильду (мгновенные обновления при hot reload), в production — глобально (с кэшированием Discord). Решение защищает dev-опыт контрибьютора: без гильдовой регистрации правки команд упирались бы в кэш Discord, и человек решил бы, что бот сломан.
