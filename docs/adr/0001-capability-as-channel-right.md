# Capability re-scoped from platform feature to channel right

Capability в прежней модели (MiA) означала «возможность платформы» (например, embed-ы на Telegram) и существовала ради деградации между платформами. Для Discord-only бота это сведено к проверке прав Bot-а в конкретном канале (embed links, attach files) перед доставкой Result-а, с понятной ошибкой при отсутствии права. Уровень «платформенных возможностей» убран: он был платой за мульти-платформу, которой больше нет.
